# Soft Serve Studio 🍦

Standalone mobile HTML5 soft-serve-making game inspired by the interaction of softserve.nog.cc. Independent implementation; original artwork and code. No downloaded assets or external JavaScript dependencies.

## Run
Open `index.html` in any modern mobile or desktop browser or upload it to GitHub Pages. The optional Google Fonts stylesheet may fail offline; fallback fonts work.

## Controls
- Swipe left/right on the screen to move the cone.
- Press and hold the pink button to dispense ice cream; release to stop.
- Tap **Finish** to see a score, **Restart** to try again.
- On desktop, arrow keys move the cone, hold Space to dispense, Enter to finish.
- Sound can be muted. Best score is saved on-device.

## Snapchat Web Lenses
Host on HTTPS with GitHub Pages, test on mobile, then enter the hosted URL into the Web Lens setup. Snapchat-specific SDK integration and a shared leaderboard are not included here. Standalone game uses 2D Canvas with dimensional shading rather than Three.js or native WebGL2.
