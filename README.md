# Soft Serve Cone Challenge
Independent fan-made browser game inspired by the movement principles observed in a gameplay recording. Not the source code or assets of softserve.nog.cc.

- Open index.html in a modern phone browser.
- Touch anywhere and move the touch-control ring at the bottom. Dispensing begins automatically.
- Cream forms a connected strand from the nozzle, a measured stack, and then topples if too high or unstable.
- Use the reset arrow for another attempt.
- GitHub Pages: upload index.html to repository root and enable Settings > Pages > Deploy from branch.
- This is an HTML Canvas approximation; precise 3D physics and fidelity to the original are not included.
